# Escuela Hi‑Lo

App web para aprender a contar cartas en blackjack con el sistema Hi‑Lo. Funciona en el móvil y en el ordenador, sin instalar nada.

## Estructura

- `index.html`: el contenido y la estructura de la página.
- `css/styles.css`: todo el diseño (colores, tipografía, tapete, cartas, versión móvil).
- `js/app.js`: la lógica de los ejercicios y de la mesa.

`index.html` enlaza el CSS con `<link rel="stylesheet" href="css/styles.css">` y el JavaScript con `<script src="js/app.js" defer></script>`.

El progreso se guarda en el navegador de cada dispositivo.
